# AGENTS.md

This repository uses `CLAUDE.md` as the primary project instruction file.

If you are an agent working in this codebase, read and follow:
- `CLAUDE.md`

In case of conflicts, prioritize the most specific and most recent user/developer instructions in the active session.

## Collaboration Preferences

- Before non-trivial edits, show the proposed change first and wait for user approval.
- For small visual tweaks, typo fixes, or single-value prefab adjustments, proceed without approval.
- Do not create commits unless the user explicitly asks for a commit.
